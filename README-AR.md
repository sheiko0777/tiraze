# إرث — المجموعة الجديدة

نسخة محلية مستقلة لمعاينة تجربة إرث في السجاد الحرير اليدوي والمقتنيات الإسلامية. المرجع البصري: https://jannat-shop.ru/، مع مراجعة النسخة المحفوظة في `../Jannat-Offline`.

## التشغيل

شغّل `START-WINDOWS.bat` ثم افتح http://localhost:8088 . يلزم Python 3 فقط. لا تفتح `index.html` مباشرة، لأن الموقع يستخدم وحدات JavaScript ومسارات صفحات.

يمكن التشغيل يدوياً من هذا المجلد:

```powershell
python -X utf8 serve.py 8088
```

## ما تتضمنه النسخة

- العربية والإنجليزية، مع حفظ اللغة.
- الصفحة الرئيسية بنفس ترتيب تجربة المرجع: افتتاحية سينمائية، فلسفة الدار، مشهد الحرفة، المجموعات الأربع، الإصدارات، المنتجات المختارة، معرض التفاصيل، الأسئلة، التواصل والتذييل.
- ٦ قطع تصورية: سجاد نور وصفاء وروضة، مسبحة أُحد، قلادة أثر، وميدالية وصال.
- كتالوج قابل للبحث والتصفية والترتيب، وأربع صفحات مجموعات.
- صفحات للمنتجات بخيارات وصور قابلة للتكبير والعناية والتوثيق.
- مفضلة وحقيبة اختيارات بكميات وتفضيلات مستقلة، محفوظة محلياً.
- طلب اقتناء محفوظ على الجهاز، مع تنزيل JSON واسترجاعه وحذفه.
- فلسفة إرث، خدمة الاقتناء الخاص، إهداءات الجهات، دليل العملاء، التوثيق، العناية، وثلاث حكايات تحريرية.
- ١١ صورة مولدة بصيغ أصلية PNG وWebP محسّنة، وخطوط محلية، وفيديو افتتاحي مولد بدقة 1920×1080 ومدته نحو ٣ ثوانٍ.

## حدود التسليم الحالية

هذه إعادة بناء مستقلة تحتفظ بالألوان الأساسية والتسلسل والتكوينات البصرية للمرجع، وليست شهادة تطابق بكسل ببكسل لجميع صفحاته. استُبدل قسم آراء العملاء بمعرض تفاصيل للمجموعة لتجنب نسبة مراجعات جنات إلى إرث أو إنشاء مراجعات غير حقيقية.

الموقع غير منشور على `irth-house.com`، ولم تُعدّل نسخة متجر إرث الحالية. لا توجد مدفوعات أو إرسال فعلي للنماذج. البيانات المدخلة تبقى في المتصفح. للتشغيل التجاري يلزم ربط منصة المتجر ونظام الطلبات وتأكيد بيانات القطع وأسعارها ومخزونها وسياسات الشحن والإرجاع.

صور الكسوة وأحجار أُحد تصورات للتصميم وليست إثباتاً للأصالة. لم تُرفق مستندات المصدر، لذلك لا توجد شهادات مختلقة أو ادعاء باعتماد قطع فعلية. صفحة التوثيق تشرح البيانات المطلوبة قبل العرض التجاري.

الفيديو الافتتاحي من Creative Claw / Gemini Omni. لم يُنتج فيديو ثانٍ: الرصيد المتبقي لا يكفي لدى Creative Claw، وRunway المتصل بخطة مجانية لا يتيح الفيديو. لم يتم شراء اشتراك أو رصيد إضافي.

## الملفات

- `app.js`: الواجهات، التنقل، التفاعلات والحفظ المحلي.
- `data.js`: بيانات القطع والمجموعات والنصوص العربية والإنجليزية.
- `styles.css`: الألوان والتقسيم والتجاوب.
- `assets/`: جميع الصور والفيديو والخطوط، ولا يعتمد العرض على روابط صور خارجية.
- `tools/assets.json`: مسارات ملفات الصور الأصلية وقت التوليد.
- `tools/prepare.py`: نسخ الصور الأصلية وتحويلها إلى WebP، ويتطلب FFmpeg لإعادة التحضير فقط.
- `tools/download_video.py` و`tools/download_fonts.py`: إعادة تنزيل الفيديو والخطوط، ولا يلزمان للتشغيل بعد وجود الأصول.
- `tools/verify.py`: فحص الملفات وJavaScript والفيديو ومسارات HTTP؛ يعمل أثناء تشغيل السيرفر، ويتطلب Node وFFprobe للتحقق فقط.

## قبل الربط بمتجر إرث

اعتماد القطع الفعلية وصورها ووثائقها، ثم الأسعار والمقاسات والمخزون، ثم ربط طلب الاقتناء بالوجهة الرسمية والدفع والشحن. هذه الأعمال تعتمد على بيانات المتجر وإعداداته وليست مفعّلة في نسخة المعاينة.
