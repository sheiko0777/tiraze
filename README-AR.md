# تيراز — Tiraze

براند للسجاد الحرير اليدوي الفاخر. طُبّقت الهوية الثالثة: Tiraze بالكحلي، Silk Rugs بالذهبي، وأيقونة T عاجية على خلفية كحلية.

للتشغيل: python -X utf8 serve.py 8090 ثم افتح http://localhost:8090.

الكتالوج الحالي يضم تصورات سجاد نور وصفاء وروضة. الطلبات تُحفظ محلياً ولا يوجد إرسال أو دفع فعلي بعد.

راجع docs/IDENTITY-IMPLEMENTATION.md للتغييرات والفحوص، وqa/ للصور الفعلية. المصدر القديم محفوظ في سجل Git ووثائقه المرجعية.

الدليل التنفيذي: [معايير هندسة تيراز](docs/ENGINEERING-GUIDELINES.md). راجع [شروط الإطلاق](docs/LAUNCH-CHECKLIST.md) و[مراجعة المستندين](docs/REFERENCE-REVIEW.md). الإطلاق التجاري المستهدف يشمل الدفع والطلبات الأونلاين، وهذه المعاينة ليست متجرًا جاهزًا للبيع بعد.
