# حالة تنفيذ تيراز

18 أكتوبر 2026 — **تطبيق تجارة يعمل محليًا؛ غير معتمد للبيع أو الإطلاق الإنتاجي بعد.**

استكمل Codex التنفيذ بعد موافقة صاحب المشروع على المتابعة عند توقف Claude بسبب حد الاستخدام. نُقلت الهوية والفيديو إلى التطبيق الجديد، ووُصلت الواجهة بخدمات فعلية بدل الاكتفاء بوحدات أولية. المعاينة القديمة والمشروع الأصلي مستقلان ومحفوظان.

## المنفّذ

- Astro SSR عربي/إنجليزي مع الصفحة التحريرية الأصلية، فيديو hero.mp4، تحكم بالتشغيل واحترام reduced motion، قائمة موبايل وحقيبة.
- Better Auth: تسجيل وبريد مؤكد، استعادة كلمة مرور، جلسات قابلة للإلغاء، TOTP وأسرار/رموز استعادة مشفّرة، وأدوار خادم مع تأكيد TOTP حديث للإدارة.
- كتالوج وفلاتر وتفاصيل منتجات، وسلة زائر تُدمج بالحساب، وعناوين مملوكة للعميل، وتسعير وشحن محسوبان على الخادم.
- إنشاء طلب بمعاملة D1 محمية: نسخة السلة والشحن والعنوان وبوابة التشغيل داخل المعاملة، حجز ذري، قروش صحيحة، قطعة فريدة، وidempotency حتى بعد إغلاق استقبال الطلبات.
- كاشير: جلسة مستضافة، inbox متين مع lease، توقيع وحقول حرجة موقّعة، تحقق مستقل من العملية عبر lookup موثق، معالجة تكرار وتأخر، تسوية جلسة ضاعت استجابتها، واسترداد بمرجع مزود محدد ومنع إعادة استخدامه، وتسجيل الدفعات الزائدة مع تنبيه واحد وردّ الدفعة المختارة بحد مستقل لكل محاولة. **الاختبارات محاكية للمزود؛ لا توجد تجربة تاجر فعلية.**
- COD حتى 10,000 جنيه شامل الشحن أو الحد الأقل للناقل؛ مراجعة موظف وانتهاء حجز، فصل تأكيد الطلب عن التحصيل وعن التسوية.
- إدارة كتالوج وأسعار ومخزون واستيراد CSV قابل للاستئناف ونشر نهائي ذري، وشحن يدوي وتتبع وتسليم ومرتجعات وإلغاء واسترداد وصلاحيات وتدقيق وبوابة استقبال طلبات.
- طلب تفصيل دائم منفصل عن الدفع، ومهام انتهاء الحجز والتسوية وoutbox بمحاولات محدودة، وبريد معطّل افتراضيًا.
- SEO وcanonical وhreflang وOpen Graph وsitemap وrobots وProduct/Offer للمنتجات غير التجريبية فقط؛ منع فهرسة التطوير والصفحات الخاصة.
- CI بفحوص وبناء واختبار متصفح، وأدوات تهيئة سر محلي ونسخ AES-256-GCM مع تحقق SQLite معزول، وأدلة تشغيل وحوادث واستعادة.

## أدلة التحقق المحلية

| الفحص | النتيجة | حدود الدليل |
|---|---|---|
| pnpm typecheck | نجاح؛ صفر أخطاء/تحذيرات/hints | التطبيق والعامل والحزم والأداة المحلية |
| pnpm test | 37 اختبارًا ناجحًا في 10 ملفات | Node + Miniflare/D1 محلي؛ مزود الدفع محاكى |
| pnpm build | نجاح SSR والعامل dry-run | لا نشر أو إنشاء موارد |
| pnpm test:e2e | نجاح: 10 سيناريوهات | النسخة المبنية على 4330؛ لا دفع/بريد حقيقي |
| pnpm audit --prod | لا ثغرات معروفة وقت الفحص | فحص registry لاعتماديات الإنتاج؛ ليس شهادة أمان |
| node tools/check_interactions.mjs | 54 فحصًا ناجحًا | المعاينة القديمة المعزولة، لا تُعد اختبارات تجارة |
| node tools/check_commerce_foundation.mjs | نجاح | أموال وCOD وشحن ومثال توقيع كاشير الرسمي ورفض العبث |

الاختبارات تشمل 100 محاولة لآخر قطعة بفائز واحد، rollback كامل عند نفاد عنصر، تكرار checkout والاسترداد، تأكيد/انتهاء COD، دفع متأخر دون حجز يتيم، صلاحيات وجلسات وTOTP فعلي، منع المصادر الخارجية، إخفاء روابط المصادقة من الإدارة، استيراد مرحلي، دورة شحن/تحصيل/تسوية/مرتجع، و1000 سجل كتالوج تجريبي. اختبار 1000 سجل يثبت البحث والتصفية والترقيم محليًا، وليس حمل إنتاج أو سرعة استيراد ملف كامل.

البيئة: Node 26.8.1، pnpm 10.30.3، TypeScript 6.0.3، Vitest 4.1.12؛ محاكي اختبارات D1 بتاريخ توافق 2026-08-01. Playwright 1.62.1 مع Chromium/Edge. نتائج المتصفح وصوره المحلية في qa/commerce عند نجاح التشغيل. اختبار النسخ يفك نسخة تركيبية إلى SQLite في الذاكرة ويكشف العبث والمفتاح الخاطئ؛ ليس استعادة D1 بعيد.

## ما يمنع البيع الحقيقي

لا توجد مفاتيح تاجر أو معاملات sandbox/live، ولا كتالوج/مخزون/منشأ وصور إنتاج معتمدة، ولا عقد ومصفوفة شحن فعلية، ولا سياسات وبيانات كيان وفواتير معتمدة، ولا بريد إرسال موثق أو تنبيه أو نسخة مستقلة مجدولة واستعادة staging. لم تُفعّل فوترة أو DNS أو نشر أو موارد سحابية.

checkout_enabled=false افتراضيًا، وكذلك عند غياب الإعداد. فتحه من الإدارة لا يعمل إلا بإذن بيئة اختبار صريح أو attestation إنتاج مع تهيئة كاشير وكتالوج ومصفوفة غير تجريبيين. هذه الإشارة ليست إثبات جاهزية تلقائيًا؛ تبقى [قائمة الإطلاق](LAUNCH-CHECKLIST.md) مرجع القبول.
