# ADR-0001: حدود التجارة ومسار الإطلاق

## الحالة

تحديث 17 أكتوبر 2026: استُبدل اقتراح المنصة المُدارة واختيارات السوق غير المحسومة بقرارات المستخدم في [ADR-0002](0002-custom-egypt-commerce.md). تبقى حدود الأمان ومصدر الحقيقة والإطلاق الكامل سارية. النص التالي سجل القرار الأصلي.

معتمد: هدف متجر كامل من أول إطلاق وفصل البيانات الحاسمة عن المتصفح. مقترح للتقييم: محرك تجارة مُدار. غير محسوم: المزود والمنصة والسوق والعملة والاستضافة النهائية.

## التاريخ

16 أكتوبر 2026.

## السياق

المشروع الحالي معاينة بواجهة HTML/CSS/JS مستمدة من إرث، بهوية تيراز، وسلة وطلبات محلية. المستخدم حدد الدفع والطلبات الأونلاين من أول إطلاق؛ لذلك لا تصلح المعاينة بوصفها محرك تجارة نهائيًا. نحتاج الحفاظ على التصميم والفيديو، مع تقليل مخاطر الأموال والمخزون والبيانات وتكلفة التشغيل.

## القرار

1. إطلاق البيع يحتاج محرك تجارة سلطويًا، وطلبات دائمة، وتحقق دفع خلفيًا، وشحنًا واسترجاعًا وتشغيلًا موثقًا.
2. نقيّم أولًا منصة مُدارة بواجهة مخصصة؛ Shopify مرشح للاختبار وليس اختيارًا تعاقديًا نهائيًا. يقاس دعم الكيان والدول والعملات والمزودين والتصميم والتصدير والتكلفة.
3. يفضل ثيم مخصص إذا حقق المتطلبات. Headless يصبح مناسبًا عندما يثبت نموذج أولي حاجة لا يحلها الثيم ضمن تكلفة مقبولة.
4. لا backend مخصص أو microservices أو Redis inventory لمجرد اتباع قالب مرجعي؛ كل خدمة جديدة لها حاجة ومالك ودليل.
5. لا يغيّر هذا ADR إطار المشروع أو يشغّل بوابة دفع تلقائيًا؛ إنه يحدد شروط تقييم البناء التالي.

## البدائل

| البديل | التقييم |
|---|---|
| الإبقاء على localStorage كطلبات إنتاج | مستبعد: لا سجل مركزي أو تحقق مالي أو اتساق مخزون |
| تجارة مُدارة + ثيم خاص | مرشح افتراضي: تشغيل أقل، مع اختبار قيود التخصيص والتكامل |
| تجارة مُدارة + frontend مستقل | بديل عند حاجة مثبتة: تخصيص أوسع ومسؤوليات إضافية عن SEO والجلسات والتكامل |
| بناء تجارة مخصصة معيارية | ممكن عند فجوة مثبتة وفريق وميزانية تشغيل؛ ليس افتراض البداية |
| خدمات مصغرة منذ البداية | مؤجل: ليس لدينا قياس يبرر كلفتها وتعقيدها |

## النتائج

كتالوج المعاينة لا يعلن مخزونًا أو أسعارًا حقيقية. تبقى الهوية مرجعًا بصريًا مستقلًا عن اختيار التقنيات. شروط الإطلاق المالية والأمنية لا تختصر بسبب نجاح اختبارات الواجهة. أي قرار منصة نهائي يصدر في ADR تالٍ، بأدلة وتجربة وتكاليف ومخاطر انتقال وخطة تصدير.
